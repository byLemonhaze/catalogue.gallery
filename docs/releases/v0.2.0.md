# v0.2.0 — Windows, Stories & Dispatch

Catalogue now brings immersive artist discovery, longer editorial work and daily digital-art news into one coherent dark interface. This release collects the work since March's v0.1.7 while keeping the core idea intact: artists own their websites; Catalogue helps people find and enter them.

## Discover independent worlds

- A new Windows WebGL carousel gives artist images depth, motion and velocity-driven deformation. Browse with touch, wheel or keyboard, pause the rotation, or use the drag control.
- Profiles open before entering a website. The preview reveals the artist's site automatically when ready; the image and Enter world action both lead inside.
- A compact, movable exit control replaces the large fixed overlay, helping avoid collisions with an artist's own navigation.
- The directory adds sorting, Shuffle and grid/list views. Unified search covers artists, galleries, Stories and Dispatch editions.

## Read Stories and daily Dispatch

- Public Content Lab becomes **Stories**, with canonical `/stories/` and `/stories/:slug/` routes. Historical `/blog/` links permanently redirect to the same story slug.
- **Dispatch** has dedicated edition and archive pages, preserving historical dates and media. The homepage uses the selected Counterpoint transcript: a single vertical masthead, quiet counter and lilac word reveals.
- Page transitions connect editorial navigation, article openings and Dispatch's aperture. Reduced-motion preferences retain readable, usable content.
- About lives at `/about/`; `/info/` redirects there. The CATALOGUE publisher byline returns to the homepage.

## A consistent identity, including mobile

- Dark-only presentation with Syne headings, Sora body text, IBM Plex Mono controls and the handwritten `.gallery` signature.
- The selected **Constellation** mark supplies vector masters, square avatar exports, favicon/device icons and branded default social previews.
- Mobile safe-area padding, clearer navigation, roomier directory/Dispatch cards and more accessible world-entry controls.
- Application forms and blocked-embed states follow the same visual system.

## Under the surface

- Server-rendered public pages and articles, canonical URLs, structured data, sitemap generation and production/preview indexing controls.
- Consistent sharing metadata with stale route tags removed during navigation; story and edition imagery remains specific to its content.
- Full-build share audits and a production smoke check for redirects, metadata and the deployed entry bundle.
- Improved application validation and embedding checks, with clearer failure states and the existing reviewed onboarding flow retained.
- Self-hosted fonts, compressed thumbnails, shared CMS reads and lazy route loading.

## Validation and limits

The preceding Stories/Constellation release passed 225 tests across 33 files. Its full SEO/share audit covered 502 pages, 321 local preview images and 174 remote images, with all remote images checked and zero failures. These are dated release-checkpoint counts, not fixed inventory promises. The publication procedure reruns verification and the full build from the merged release commit.

The main client bundle still emits Vite's size advisory (about 612 kB minified / 179 kB gzip at that checkpoint). WebGL performance varies on lower-powered devices; reduced motion remains available. External websites can block embedding, and social services may retain cached previews. Existing dependency-security alerts are not resolved by this product release.
